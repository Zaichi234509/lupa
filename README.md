# Lupa – Champion of the Great Agon

A stunning fan page for Lupa, the undefeated she-wolf gladiator from Wuthering Waves. Built with modern HTML, CSS, and JavaScript featuring particle effects, 3D tilt interactions, and smooth scroll animations.

## 🌐 Live Demo
[View Live Site](https://zaichi234509.github.io/lupa/)

## ✨ Features
- **Immersive Design**: Dark void theme with ember/gold accents inspired by Lupa's Fusion element
- **Particle System**: Floating ember particles using HTML5 Canvas
- **3D Tilt Card**: Interactive hero card with mouse-based 3D rotation
- **Scroll Animations**: Smooth reveal effects as you scroll through sections
- **Responsive Layout**: Fully responsive for mobile and desktop
- **Video Background**: Dynamic background video for atmosphere
- **Modal System**: YouTube gameplay video modal

## 🎨 Tech Stack
- HTML5
- Tailwind CSS (via PostCSS)
- Custom CSS animations
- Vanilla JavaScript (no frameworks)
- Phosphor Icons

## 🚀 Local Development
```bash
npm install
npx tailwindcss -i ./src/input.css -o ./styles.css --watch
```

## 📦 Deployment
This site is hosted on GitHub Pages. To deploy your own version:
1. Fork this repository
2. Enable GitHub Pages in Settings → Pages
3. Select branch: `main` and folder: `/ (root)`
